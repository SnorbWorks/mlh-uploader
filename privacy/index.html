MLH Uploader privacy policy

Last updated November 24, 2026.

MLH Uploader is a personal tool run by the owner of the My Latest Hyperfocus YouTube channel, on the owner's own computer.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload videos to the owner's channel, set thumbnails and captions, edit titles and descriptions, add videos to playlists, and change a video's privacy setting. It does not access any other Google data and does not access anyone else's account.

Where data is stored

The sign-in token is saved only on the owner's computer. Nothing is sent to any server other than Google's own APIs. No data is collected from viewers or other users.

Sharing

MLH Uploader does not sell, share or transfer any data to anyone. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
